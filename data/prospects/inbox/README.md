# Prospect inbox

Drop files here and the monthly prospects run (or `python -m mma_predictor tapology-import`) imports them:

- **Tapology pages you saved** in your browser (File > Save page as, "Web page, complete" or "HTML only"):
  someone's ranking list ("My Rankings", community rankings) or a fighter page.
- **A pasted list** as a `.txt` file: one fighter per line. Put who made it, the title and the date
  on the first three lines like this:

      author: Hellowhosthat
      title: Flyweight prospects outside the UFC
      date: 2026-09-14

Each list becomes dated calls by its author, graded on what the fighters do next. Imported files
are removed from this folder; this README stays.
